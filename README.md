# 🏥 X Hospitals: Leads Flow Dashboard

An interactive **Power BI dashboard** built for **X Hospitals** to monitor and manage patient flow, diagnosis trends, billing, and operational performance.

---

## 🧰 Tools & Technologies Used

| Tool / Technology | Purpose                                 |
|-------------------|------------------------------------------|
| Power BI          | Data visualization and dashboard design  |
| DAX               | Custom calculations and KPIs             |
| Power Query       | Data transformation and loading          |
| Excel / CSV       | Source data files (imported to Power BI) |
| Date Slicers      | Filtering time ranges                    |
| Dropdown Filters  | Dynamic patient or attribute filtering   |
